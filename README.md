# London Schools Explorer 🏫

A free, data-driven directory of **every London school** — searchable by Ofsted rating, borough, phase, admissions oversubscription, exam results and local crime data.

🌐 **Live site:** [londonschool.directory](https://londonschool.directory)

---

## What it does

- **Find schools near you** — enter any London postcode to see nearby schools ranked by Ofsted rating, distance and admissions competitiveness
- **Compare schools side by side** — select up to 3 schools and compare across 13 data points
- **Admissions appeals tracker** — borough-level appeal success rates with trend data 2016–2024
- **Map view** — all London schools plotted on an interactive map
- **Stats dashboard** — borough breakdowns, rating distributions, phase splits

## Data sources

| Data | Source | Updated |
|------|--------|---------|
| School list, phase, type | [GIAS](https://get-information-schools.service.gov.uk/) | Monthly |
| Ofsted ratings | [Ofsted MI](https://www.gov.uk/government/statistical-data-sets/monthly-management-information-ofsteds-school-inspections-outcomes) | Monthly |
| KS2 attainment | [DfE EES](https://explore-education-statistics.service.gov.uk/find-statistics/key-stage-2-attainment) | Annual |
| KS4 Attainment 8 | [DfE Performance Tables](https://explore-education-statistics.service.gov.uk/find-statistics/key-stage-4-performance-revised) | Annual |
| Admissions (apps per place) | [DfE EES](https://explore-education-statistics.service.gov.uk/find-statistics/secondary-and-primary-school-applications-and-offers) | Annual |
| Crime within 500m | [Metropolitan Police API](https://data.police.uk/docs/) | Monthly |
| Deprivation (IMD) | [MHCLG](https://www.gov.uk/government/statistics/english-indices-of-deprivation-2019) | Static |
| School profile links | [Snobe.co.uk](https://snobe.co.uk) | Monthly |

All data is open government data published under the [Open Government Licence](https://www.nationalarchives.gov.uk/doc/open-government-licence/).

## Tech stack

- **Frontend:** Vanilla HTML + React (CDN) — single `index.html` SPA homepage
- **School pages:** Static HTML generated by `build_school_pages.py` — one page per school
- **Hosting:** [Vercel](https://vercel.com) — auto-deploys on every GitHub commit
- **Data pipeline:** GitHub Actions — runs on the 15th of every month
- **No database** — everything served as static files for maximum speed and zero cost

## Monthly data pipeline

The GitHub Actions workflow (`monthly_refresh.yml`) runs automatically on the **15th of every month** at 08:00 UTC:

1. `refresh_data.py` — fetches fresh data from GIAS, Ofsted, EES and Police API
2. `reset_snobe_urls.py` — regenerates every school's Snobe profile URL
3. `check_snobe_slugs.py` — validates URLs against live Snobe site
4. `build_school_pages.py` — rebuilds all static pages with fresh data
5. Commits updated files back to GitHub
6. Vercel auto-redeploys on the new commit

To trigger manually: **Actions → Monthly Data Refresh → Run workflow**

## Running locally

```bash
# Install dependencies
pip install requests pandas numpy pyyaml

# Fetch fresh data
python3 scripts/refresh_data.py

# Build static pages
python3 scripts/build_school_pages.py

# Serve locally
python3 -m http.server 8000
```
